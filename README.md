# automotive-seru-reconfiguration

本仓库为论文《基于分阶段约束处理的汽车总装seru生产系统动态重构优化方法》的核心代码。

This repository contains the core code for the manuscript "A staged constraint-handling approach to dynamic reconfiguration of automotive final-assembly seru production systems".

## 运行

```bash
pip install -r requirements.txt
python tests/sanity_checks.py
python examples/run_demo.py
```
